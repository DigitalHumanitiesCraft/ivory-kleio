# Source material

The [corpus inventory](../research-artefacts/corpus.csv) records published works and the representations consulted for research. Original project notes are held in [reading notes](../research-artefacts/reading-notes/).

Download source files into the ignored `local/` directory when a reading task needs them. Record the exact representation URL, acquisition date and content hash with the source record. Keep the distinction between the publication date and the date of a later access copy.

A publicly accessible text retains its own reuse conditions. Add third-party files to the repository only when the applicable terms permit that redistribution. Bibliographic links and original research notes can establish a reviewable source basis before any such redistribution.

Historical source datasets require a source-location scheme and recorded reuse conditions before they become test fixtures. The initial acceptance cases use explicitly invented data.
